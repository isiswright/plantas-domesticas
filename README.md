# Raiz & Lar — redesign editorial

Site educativo de plantas domésticas (HTML, CSS e JavaScript), com catálogo, busca, filtros, favoritos e fichas de cuidados.

## Como publicar no GitHub Pages

Envie **os cinco arquivos desta pasta** para a raiz do repositório `plantas-domesticas`, substituindo os anteriores: `index.html`, `style.css`, `plants.js`, `app.js`, `README.md`. Depois, em Settings > Pages, use branch `main` e pasta `/(root)`.

## Observações

As fotografias são decorativas, hospedadas externamente, e **não correspondem necessariamente à espécie indicada**. Devem ser substituídas por fotos identificadas e licenciadas adequadamente antes da entrega final. Os dados de cultivo e toxicidade são educativos e precisam de validação botânica/veterinária.
